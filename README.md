## 🚀 What I'm Building

### 💬 Anonymous Conversation Platform

A real-time, anonymous, topic-oriented communication platform.

The idea is to allow people to communicate around **ideas and conversations without requiring a permanent identity**.

Participants receive temporary identities, discover or create conversations, and communicate through those conversations.

The project focuses on:

- Backend architecture
- Real-time communication
- Anonymous session management
- PostgreSQL data modeling
- API design
- Security and abuse considerations
- Testing
- Documentation
- Maintainable engineering practices

**Technology direction:** TypeScript · React · Vite · Fastify · PostgreSQL

The project is currently in its **early design / pre-implementation stage**, with product requirements and system design being defined before the main implementation.
